# Product requirements document

This is a KMP Port of the Decide-O-Mat web tool. It should add to native apps (Android and iOS) that match the 
featureset of the original web frontend, and communicate with the existing cloud functions based backend. The Apps 
should also function as a trust anchor, as the web variant cannot really guarantee user identification. 

The original specification can be found in the decide-o-mat web repository which is added as a git submodule in the 
decide-o-mat directory. Use this specification as a base for this repositories specifications under the normal specs/ 
directory. When creating new stories, link to the original story ID in the decide-o-mat repo.
